# 🌴 Turismo Frontend

Frontend de una plataforma de reservas y ofertas turísticas desarrollada con Reflex.

## 📖 Descripción

Esta aplicación permite a los usuarios explorar destinos turísticos, consultar información detallada de cada actividad y realizar reservas en línea.

Cuenta con una interfaz moderna, responsive y conectada a una API REST para gestionar reservas y ofertas.

## ✨ Funcionalidades

- Página de Inicio
- Página de Descripción de destinos
- Página de Reservas
- Diseño Responsive
- Integración con API REST
- Navegación entre páginas
- Formulario de reservas

## 🛠 Tecnologías Utilizadas

- Python
- Reflex
- Poetry
- HTML/CSS (a través de Reflex)
- Render
- GitHub

## ⚙️ Instalación

Clonar el repositorio:

```bash
git clone https://github.com/felixalcap-hash/turismo-frontend.git
```

Entrar al proyecto:

```bash
cd turismo-frontend
```

Instalar dependencias:

```bash
poetry install
```

Ejecutar localmente:

```bash
poetry run reflex run
```
